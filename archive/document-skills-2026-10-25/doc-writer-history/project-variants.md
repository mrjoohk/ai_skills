# 프로젝트에서 가져온 기능과 적용 조건

## 비교 대상

2026-10-25에 `drmHWP/tools/doc-writer`, `drmHWP/tools/hwpx-drm`, 두 프로젝트의 `.claude/skills/`와 `.codex/skills/`를 비교했다.
원본 프로젝트의 스킬·도구·문서·설정은 변경하지 않았다.

| 프로젝트 | 확인한 특징 | 이 라이브러리에 적용한 방법 |
|---|---|---|
| drmHWP | 실제 문서 작성기, 표 서식 처리, 그림 추출, 기존 문서 끼워 넣기, 그림 꾸러미, 가짜 COM 시험 | 실행 도구를 `runtime/`, 필요한 한글 시험·합성 fixture를 hwpx-drm에 보관 |
| surak | 엔지니어링 스킬은 동일. 문서 스킬은 끼워 넣기·그림 꾸러미 추가 전 버전이며 DRM 그림 추출을 제한하는 프로젝트 규칙을 포함 | 현재의 기능을 이전 판으로 되돌리지 않고, 프로젝트별 취급 조건이 다르다는 점을 유지 |

기능이 존재한다고 해당 프로젝트에서 사용할 수 있다는 뜻은 아니다. 특히 drmHWP의 과거 D-062 승인으로 surak의 D-028 제한을 해제하지 않는다.
작업 대상의 현재 규칙과 이미 허용된 요청 범위를 우선한다.

## 포함한 실행 도구

- `write_doc.py`: 템플릿과 내용 명세로 문서를 새로 작성하고 저장 후 대조한다.
- `insert_doc.py`: 사용자가 편집한 문서를 전체 재생성하지 않고 제목 앞에 블록을 추가한다.
- `figure_pack.py`: 출처 그림을 보호 문서 꾸러미로 만든다.
- `extract_figures.py`: 평문 HWPX의 그림 파일을 추출·변환한다.
- `table_style.py`: 표 서식 해석·선택·문자 폭·크기 계산을 수행한다.
- `fake_write.py`와 `tests/`: 한글 앱을 열지 않는 합성 문서·가짜 COM 검증이다.

설치 후 새 프로젝트에서 `.hwpx` 템플릿·표 서식·출처를 지정해야 한다. 원본 프로젝트의 실제 업무 문서, 이진 템플릿, 캡처 보고서와 배포 지문은 배포 원본에 넣지 않았다.

## 시험 범위

일반 시험은 `python -m unittest discover -s tools/doc-writer/tests`로 실행한다.
특정 SUM 문서에 고정된 시험 3개는 일반 배포에서 제외되며, 원래 fixture와 `DOC_WRITER_DRMHWP_PROFILE=1`이 모두 있는 경우에만 실행한다.
`samples/minimal_spec.md`는 일반 시작점이다. 기존 `new_doc_spec.md`와 `probe_spec.md`는 drmHWP 서식·판정 예시로 유지한다.
가짜 COM 시험 통과는 실제 한글·DocuRay 환경에서 새 프로젝트 문서를 검증한 결과를 대신하지 않는다.
