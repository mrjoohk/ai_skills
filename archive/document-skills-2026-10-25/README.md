# 문서 스킬 통합 전 자료

분리 스킬의 지침과 이전 프로젝트의 서식·승인 이력, 구형 PowerShell 실행기 및 프로젝트 전용 시험을 보존한다. 활성 스킬은 skills/pipelines.json에 등록된 정본을 사용한다. 이 폴더의 과거 지침을 현재 작업의 승인이나 검증 결과로 적용하지 않는다.

- Office 판독·편집·한글 진입점 → doc-writer
- 제안서 5개 장 작성 → defense-proposal-writer
- doc-writer-history → 프로젝트별 서식·변형·원본 전용 시험
- legacy-office-scripts → 대체된 PowerShell 실행기
