# 최소 작성 명세

경로는 대상 프로젝트 루트 기준이다. 내용·목차·출처는 현재 요청에 맞게 바꾼다.

```json
{
  "template": "document_templates/technical-report/template.package.zip",
  "profile": "technical-report",
  "out": "output_docs/document_out.hwpx",
  "table_style": null,
  "protection": "preserve",
  "keys": {}
}
```

# 개요
> 문서의 목적과 범위를 작성한다.
## 적용 범위
> 대상 시스템과 사용자를 작성한다.
# 사용 절차
1) 출처에서 확인된 첫 단계를 작성한다.
2) 출처에서 확인된 다음 단계를 작성한다.
