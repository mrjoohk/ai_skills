# 한글 구조 판독과 부분 편집

실행 파일은 `<skill>/backends/hwp/scripts/hwpx_drm.py`, 프로젝트 설치 후에는 `tools/hwpx-drm/scripts/hwpx_drm.py`다. 지원 명령과 실제 인자는 `--help`로 확인한다.

먼저 텍스트와 필드·표·그림 구조를 판독하고, 실제 키·좌표를 찾아 해당 위치만 변경한다. `images`는 그림을 평문 파일로 추출한다. 문서 안에서만 그림을 옮길 때는 작성기의 `figure_pack.py`를 사용한다.

저장은 `preserve`로 원본의 보호 조건을 유지한다. `required`는 출력 보호를 요구한다. 보호 원본을 평문으로 저장한 결과는 성공으로 보고하지 않는다.

앱이 실제로 문서를 열었는지, 저장 후 다시 열린 문서의 필드·내용이 기대와 같은지 확인한다. 보호 표시만으로 내용 검증을 대신하지 않는다. 일반 `.hwpx`와 번들 `.package.zip` 템플릿은 HWPX 형식으로 연다.
