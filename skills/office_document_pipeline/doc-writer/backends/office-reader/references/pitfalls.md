# Office COM 판독 주의사항

- 확장자보다 파일 머리를 먼저 확인한다. OOXML·OLE2·DocuRay는 서로 다르며, 열기 암호와 문서 보호도 별개다.
- 앱 열기 실패는 암호·권한·손상·COM 실행 환경을 구분해 보고한다. 실패 원인을 권한 부족으로 단정하지 않는다.
- pywin32 동적 디스패치는 생략된 인자 사이의 이름 인자를 버릴 수 있다. `Open` 등의 취약한 호출은 자리 인자와 `pythoncom.Empty`를 사용한다.
- Excel `UsedRange.Value2`는 배열로 받되 단일 셀의 스칼라를 구분한다. 서식 때문에 범위가 커질 수 있으므로 상한을 적용하고 잘린 행·열 수를 알린다.
- 병합 셀의 값은 실제 `MergeArea`의 좌상단에서 가져온다. 열 방향 전방 채우기로 빈 값을 만들지 않는다. VT_ERROR 셀 값은 SCODE를 오류명으로 변환한다.
- Word `Content.Text`의 문단 끝 `\r`과 셀 끝 `\x07`을 구분한다. 스타일·각주·머리말 등 추가 구조가 필요할 때만 개체를 순회한다.
- PowerPoint는 창 숨김을 거부할 수 있다. `WithWindow=False`와 실제 보이는 사용자 창을 구분한다. COM 프로세스가 잠시 남아 있다는 이유만으로 사용자 문서가 열렸다고 판단하지 않는다.
- 표·그룹·SmartArt는 `HasTextFrame`만으로 수집되지 않는다. 표 셀·GroupItems·AllNodes를 각각 처리한다. 도형은 z-order로 반환되므로 필요하면 Top·Left로 정렬한다.
- 다이어그램과 스크린샷의 의미는 텍스트 추출만으로 검증하지 않는다. 요청된 범위에서 시각 자료를 확인한다.
- 암호 대화상자가 생겨 무한 대기하지 않도록 비밀번호 인자·timeout을 사용한다. PowerPoint처럼 암호 인자가 없는 메서드의 제한은 결과에 알린다.
- 빈 결과·잘린 미리보기·추출 실패를 서로 구분한다. 키 매칭이 0건이어도 본문이 비었다고 보고하지 않는다.
- `finally`에서 자신이 연 문서의 Close와 자신이 만든 앱의 Quit을 수행한다. 예외 처리는 `safe(lambda: app.Quit())`처럼 속성 조회도 포함한다. 전체 Office 프로세스를 종료하지 않는다.
- 한글 출력을 파일로 남길 때는 도구의 `--log`·`--dump` 인코딩을 사용한다. Windows PowerShell 5.1의 스크립트 소스와 셸 리다이렉트 인코딩은 Python 파일의 UTF-8과 구분한다.
- 덤프와 내보낸 그림은 별도 사본이다. 현재 요청에서 정한 위치·취급 범위로 저장하며 과거 프로젝트의 허용 이력을 적용하지 않는다.
