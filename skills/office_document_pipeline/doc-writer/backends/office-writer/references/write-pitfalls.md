# Office 편집과 저장 주의사항

- 출력 기본값은 원본과 다른 사본이다. 기존 파일 수정 요청이 허용하는 범위에서만 덮어쓴다. 덮어쓰기는 백업과 임시 저장본을 만들고 보호·내용 확인 후 교체한다.
- 대상 문서의 잠금 파일과 사용자 창을 확인한다. 사용자가 편집 중인 문서를 일괄 종료하지 않는다.
- 저장 정책은 `--protection preserve`가 기본이다. 원본이 보호됐거나 `required`·`protect`를 지정하면 보호가 필수다. 일반 문서는 올바른 OOXML 저장본도 허용한다.
- `verify_protection.py`는 저장본의 서명을 확인한다. 서명만으로 바뀐 내용이 올바르다고 판단하지 않는다. 실제 다시 열기와 변경 결과도 확인한다.
- Word·PowerPoint의 SaveAs 계열 메서드와 Excel의 SaveAs는 대상 형식·열기 인자·잠금 동작이 다르다. 도구가 지원하는 형식과 실제 COM 인자 순서를 사용한다. 확장자만 바꾸지 않는다.
- 텍스트 치환과 템플릿 키 채우기는 다르다. 실제 키·일치 개수·남은 자리표시를 확인하고, 빈 값을 지울지 유지할지는 현재 명세에 따른다.
- 표·머리말·꼬리말·그룹 도형의 텍스트는 본문과 별도 개체일 수 있다. 해당 위치의 지원 범위를 확인하고, 처리하지 못한 위치를 결과에 남긴다.
- Excel 수식과 셀 서식, Word 문단 스타일, PowerPoint 도형 배치를 가능한 한 유지한다. 전체 문서 재생성은 그 작업이 요청됐을 때 사용한다.
- COM 정리는 자신이 만든 인스턴스와 연 문서에 한정한다. Quit의 속성 조회도 예외 처리에 포함한다.
- 저장 실패나 보호 필수 조건 위반 파일은 성공 산출물로 전달하지 않는다. 도구가 남긴 임시·격리 경로와 원본 보존 여부를 보고한다.

현재 CLI 옵션은 `backends/office-writer/scripts/write_office_doc.py --help`로 확인한다. 과거 프로젝트의 승인·폴더명·검증 이력은 새 작업의 전제조건이 아니다.
