# 트리아지 프로토콜 (세부)

트리아지의 목적은 두 겹이다: **검증자(감사자)의 환각을 걸러내고**, 채택된 발견이 **닫힐 때까지 추적되게** 만든다.

## 게이트 순서와 근거

### ⓪ U-의존 게이트 — 채택 전 최우선
발견의 "의존" 필드가 "없음"이 아니거나, 판정 논리가 열람 불가 원본(ICD 원본, 암호화 문서, 외부 시스템)에
걸려 있으면 **심각도 불문 채택 금지**. UNVERIFIABLE로 이동하고 사용자 확인 요청으로 라우팅한다.

근거(판례): 과거 감사에서 감사자가 U-항목("설정 파일을 열람하지 못했다")을 명시했는데도 트리아지가
이를 해소하지 않고 CRITICAL로 채택했고, 그 결과 잘못된 수정이 적용됐다 롤백됐다. 정작 해당 설정 파일에는
해명("대응 필드 없음 — 원본 공백")이 이미 적혀 있었다. **U-게이트는 이 사고의 재발 방지 장치다.**

### ① 인용 실재
file:line을 직접 Read해 인용문을 원문과 대조한다. 불일치 = REJECTED-MISQUOTE (검증자 환각 — 기록도 데이터다).

### ② 기재된 해명
파일 안에 판단 근거·가정·의도 기록이 있어 지적이 해명되는가. 해명 위치를 인용해야 기각 가능.
해명이 파일에 **없으면** 기각이 아니라 "판단 근거 미기록"(억지 축)으로 **전환 채택**한다.
세션 기억("내가 알기로는 그때 이런 이유였다")은 기각 사유가 될 수 없다 — 파일 인용만 인정.

### ③ 실질성
수정해도 실제로 나아지지 않는 지적(스타일, 취향, 무해한 표기)은 REJECTED-TRIVIAL.

## 재발 대조 (필수 산출물)

1. 대조 원본 우선순위: `graph/edges.csv`의 open/deferred 전수 → 없으면 직전 감사 리포트.
2. ACCEPTED 각각에 **RECURRING**(이전에 보고된 동일/동계 결함) 또는 **NEW** 태그.
3. 이전 open 중 이번 감사에서 해소 확인된 것은 **RESOLVED**로 상태 전이 기록.
4. 리포트에 대조표(재발 n / 신규 n / 해소 n)가 반드시 있어야 한다.

근거(판례): 이 단계를 생략한 감사에서, CRITICAL의 절반 이상이 직전 감사에 이미 있었던 재발분이라는
사실이 한 세션 늦게 드러났다. 재발률은 감사 건수보다 중요한 건강 지표다 — 재발률 ≈ 0이 목표.

## Delta 모드 처분 (D4·D5)

같은 날 변경 검토는 회차가 여러 번이다 — 회차마다 **처분표**(`assets/disposition_template.md`)를 파일로 남기고,
다음 회차는 앞 회차 처분표와 대조한 뒤에 띄운다.

1. 처분 대상은 '발견' 전부와 **'결함 아님'이라 적힌 설계 메모** 전부다. 메모를 빼면 처분표가 미완성이다.
2. ACCEPTED-AS-DESIGN(설계로 받아들임)은 대표 데이터로 돌려 본 결과 수치가 근거여야 한다 — '줄 수가 비슷해진다' 같은
   말뿐인 근거는 불충분.
3. DEFERRED 는 사유와 해제 조건을 적고 대장에 deferred 로 등록한다.
4. 재발 대조: 새 회차 지적이 앞 회차의 DEFERRED·ACCEPTED-AS-DESIGN 항목과 같은 영역이면 RECURRING(앞 회차 ID).
5. 고침 확인(D6) 결과는 '비독립'으로 표시하고, 독립 검토 통계(재발률 등)와 섞지 않는다.

근거(판례): drmHWP P-041 — 1회차가 '비율로 나누면 긴 칸이 짧은 칸보다 좁아질 수 있다'(설계 메모)와 '긴 낱말 하나가 모든 칸을
줄인다'(M2)를 짚었으나, 메모는 말로만 받아들이고(실제 표로 돌려 보지 않음) M2 는 반만 고쳤다. 앞의 것은 가짜 전체 쓰기에서
문서번호 칸 8.8mm 로, 뒤의 것은 2회차에서 같은 영역으로 다시 나와 한 바퀴(약 30분)가 더 돌았다. 보고가 파일로 남지 않아
맥락 압축 뒤 대조도 못 했다.

## 기각 분류 요약

| 분류 | 의미 | 기록 가치 |
|---|---|---|
| REJECTED-MISQUOTE | 감사자가 인용을 지어냄 | 검증자 신뢰도 데이터 |
| REJECTED-JUSTIFIED | 파일 내 해명이 존재 | 해명 위치가 곧 문서화 품질 증거 |
| REJECTED-TRIVIAL | 실질 개선 없음 | 루브릭 조정 신호 |

모든 채택/기각에 판단 근거를 명시한다. 세션 맥락 사용은 트리아지에서만 허용된다.
