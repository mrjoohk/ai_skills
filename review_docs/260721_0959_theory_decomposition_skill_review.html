2. 아이디어 검토

주장: 도메인 오픈소스 코드가 없어도, 이론을 작은 이론으로 반복 분해하고 각 하위이론의 수식을 연동·머지하면 원래 이론의 수식·동역학을 재구성할 수 있다.

검토 결론: 타당하며, 기존 파이프라인과 구조적으로 동형(isomorphic).
이 아이디어는 현재 스킬 수트가 소프트웨어에 적용하는 원리(시스템→IF→UF 분해 후 상향 통합)를 이론·수식 수준에 적용한 것과 정확히 같음. 신규 스킬 1개를 프론트엔드로 추가하면 기존 파이프라인에 그대로 연동 가능.

3. 리스크 3건 및 대응 (아이디어가 그대로는 성립하지 않는 지점)

R1. 가정 비호환 머지. 수식은 코드와 달리 가정·유효범위를 가짐(선형화, 강체, 비압축성, 소각 근사 등). 타입·단위가 맞아도 가정이 충돌하면(예: 강체 가정 수식 + 유연체 수식) 머지 결과가 조용히 틀림.
대응: EQ Block에 Assumptions, Validity Domain, Frame 필드를 추가하고, 머지 전 가정 호환성 매트릭스 검사를 게이트로 삽입.
R2. 창발적 결합항 누락. 상향 머지는 하위이론 어디에도 없는 교차항을 놓칠 수 있음(예: 회전좌표계+병진 머지 시 Coriolis·자이로 모멘트 항, 다물리 연성항). 순수 bottom-up만으로는 원래 이론과 등가가 보장되지 않음.
대응: 기존 Stage 7.5(UF→IF 커버리지 리뷰, UNCOVERED 플래그)의 이론 버전을 추가 — 보존법칙(에너지·운동량), 극한 케이스 환원(감쇠→0 시 단순조화진동 등), 차원 분석으로 머지 결과가 원래 이론의 알려진 거동을 커버하는지 검사.
R3. 참조 구현 부재 시 검증 오라클. 오픈소스가 없다는 전제이므로 "정답 코드와 비교" 불가. LLM 수식 환각 위험도 존재.
대응: ① 각 EQ Block에 출처(교과서·논문 식 번호) Evidence 필드 필수화, ② 오라클을 차원 분석·극한 케이스·보존량·대칭성·논문 벤치마크 수치로 구성해 eval-planner 지표로 등록. sim-physics-auditor가 이 중 단위·차원·안정성을 이미 커버.
판단 근거: R1·R2는 기존 파이프라인에 개념적 대응물이 이미 존재(I/O 계약 검사, Stage 7.5 커버리지 리뷰)하므로 "확장"으로 해결 가능하고 새 메커니즘 발명이 불필요. R3는 이 스킬 수트의 Evidence 원칙("모든 주장은 증적 필요", core-engineering Rule 4)을 수식 출처로 확장하는 것으로 충분. 세 리스크 모두 스킬화를 막는 결격 사유가 아니라 EQ Block 필드·게이트 설계 요건임.

분해 깊이 기준 (정지 조건)

말단(원자) 이론 판정 — S1~S4를 모두 만족하면 분해 정지, 하나라도 불만족이면 계속 분해:

#정지 조건근거
S1단일 수식(또는 폐형 연립 1세트)으로 기술 가능UF의 SRP(단일 책임) 아날로그 — EQ Block 1개 = 수식 1개
S2출처 1건으로 직접 인용 가능 (교과서 식 번호·논문)더 쪼개면 출처가 사라짐 → 수식 환각 위험 증가 (R3)
S3단독으로 차원 검사·극한 케이스 검증 가능Stage 6 분해 기준(testability) 아날로그
S4추가 분해가 새로운 가정(assumption)을 분리하지 못함분해의 목적 = 가정 분리(R1 대응) — 가정이 더 안 나뉘면 분해 이득 없음

과분해 가드: 기본 깊이 상한 4 (초과 시 WARN — 머지 비용이 분해 이득을 초과). 상한은 스킬 파라미터 max_depth로 조정.

EQ Block = UF Block + 4개 필드

EQ-ID, Parent Theory, Goal, I/O Contract(변수: type·unit·frame·range)는 UF Block 그대로 유지하고, Equation(수식), Assumptions(가정), Validity Domain(유효범위), Source(출처: 교과서/논문 식 번호)를 추가. 블록 문법이 같으므로 uf-implementor가 eq.md를 그대로 소비 가능.

연동 파이프라인

검증 예시 (미니 워크스루: 쿼드로터 6-DOF)

T0 예시: 쿼드로터는 PX4·논문 벤치마크가 존재 → FOUND-CODE 판정, 재구성 결과를 참조 구현과 교차 검증하는 모드로 진행. 반대로 완전 신규 도메인이면 NONE → 보존법칙·극한케이스 오라클 모드.

분해: 강체 병진(뉴턴 제2법칙) / 강체 회전(오일러 방정식) / 로터 추력·토크 모델 / 중력. 각각 EQ Block으로 작성 후 머지하면 T3.5 게이트가 다음을 잡아냄 — ① 병진식은 관성계, 회전식은 동체계 → Frame 필드 불일치로 회전행렬 R 삽입 요구, ② 커버리지 리뷰의 극한 케이스("고속 요잉 중 피치") 체크에서 하위이론 어디에도 없는 자이로 결합항 ω×Jω 누락을 UNCOVERED로 플래그. 이는 R1·R2 대응 장치가 실제로 작동함을 보여주는 사례.
